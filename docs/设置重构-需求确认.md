# 设置重构 · 需求确认（讨论稿）

> 状态：第一批已实施（2026-11-16），第二批待实施
> 范围：思源插件 `siyuan-pdf-zotero` 的「设置」对话框重排 + 缺失设置补齐
> 记录日期：2026-11-16

---

## 0. 一句话目标

把现在 8 个零散一级页、25 项“有功能没入口”的设置，收敛成 **5 个一级页 + 页内按主题分组** 的结构，补上搜索、即时生效、导入导出、恢复默认，并把 OCR/翻译/阅读相关配置各自归位。

---

## 1. 现状问题（审计结论）

- 设置项共 **98** 个；设置对话框现有 **8** 个一级页：`Zotero 与阅读 / 选区翻译 / PDF 问答 / 整篇翻译 / Doc2X / OCR / PDF2zh / AI 自动化`。
- **25 项有值、有行为，但不在设置对话框里**：
  - 阅读器内按钮/小窗：链接复制格式、显示文本格式与模板、链接模板、PDF 标注写回；
  - 独立弹窗：笔记模板与标题规则、翻译服务管理；
  - 无任何入口：Zotero 直读 PDF（directFsRead）、QA 面板尺寸。
- **零散/重复**：
  1. 目标语言 3 套（选区翻译 / PDF2zh / Doc2X）；
  2. OCR 格式 4 处，选项集合互不一致（设置页 2 项、路由区 9 项、弹窗复制格式 10 项、弹窗插入格式 6 项）；
  3. 整篇翻译被拆到 3 个一级页（整篇翻译 / PDF2zh / Doc2X）；
  4. OCR 页一页塞三件事（引擎卡片、识别路由、识别行为）；
  5. 旧兼容键仍在 Schema 中但无 UI；
  6. 通用能力缺失：无搜索、无恢复默认、无导入导出、无逐项说明、保存/即时生效不一致。

---

## 2. 目标结构（已确认）

```
连接与阅读  |  翻译  |  OCR  |  AI 与自动化  |  高级
```

页内按 **“翻译 / OCR 识别”两大主题** 归组；`翻译`、`AI 与自动化` 页内用子 tab，`OCR` 页内用折叠块。

### 2.1 连接与阅读
本批保留项：
- Zotero Local API 地址、数据目录、库 ID
- 悬浮预览触发方式（直接悬停 / Alt+悬停）
- 摘录可见模板（{text}/{page}/{title}）
- 默认引用样式
- **笔记模板（新增）**：默认模板选择、新笔记目录、标题 pattern
- 每项一行中文说明

> 本批**不加入**（见 §7 待办）：链接复制格式 / 显示文本模板、PDF 标注写回开关、Zotero 直读 PDF 开关。

### 2.2 翻译（子 tab：选区 / 整篇 / 服务）
- **选区翻译**：启用、选中自动翻译、译文显示原文、最短字符、目标语言（默认继承，可覆盖）
- **整篇翻译**：提供方（PDF2zh / Doc2X）、译文输出目录、目标语言（默认继承，可覆盖）
  - PDF2zh 参数：地址、服务目录、引擎、服务名、源/目标语言、输出模式、对照方向
  - Doc2X 参数：CLI 命令、鉴权模式、目标语言、输出模式、模型、术语表、字体策略、忽略类型、上下文增强、保留字体颜色、检测环境/刷新模型
- **服务（新增子 tab）**：内嵌翻译服务列表（启用、选择、排序）；点某项打开详情弹窗编辑 baseURL / API Key / 模型；**改完即时生效 + 测试连接按钮**
- **目标语言规则（新增）**：一个“默认目标语言”字段；选区 / PDF2zh / Doc2X 默认跟随，可各自覆盖；跟随状态在界面上以“跟随默认”字样呈现

### 2.3 OCR（一页三折叠块）
1. **引擎与服务**
   - 每个引擎卡片：启用、服务目录、端口、自动启动、状态
   - 卡片操作：**检测 + 启动 / 停止 / 重启**
   - 共享 Python 运行时目录、自定义启动命令
2. **识别路由**
   - 公式引擎优先级（Texo > UniMERNet > Pix2Text 拖拽/下拉排序）
   - 文本识别引擎选择
3. **行为与格式（全部引擎共用）**
   - 默认模式（自动 / 公式 / 文本）、默认后置动作、识别语言、历史条数、超时、识别后先预览编辑
   - **OCR 弹窗默认值（新增）**：默认预览渲染器（KaTeX / MathLive）、识别后自动复制开关、默认复制格式、默认插入格式
   - 公式格式统一为 **6 种 LaTeX 包装**：`$...$`、`$$...$$`、`\(...\)`、`\[...\]`、`align`、`equation`
   - 复制格式集合 = 6 种包装 + `LaTeX 原样` + `Markdown` + `Typst` + `MathML`（共 10 项，三处一致）

### 2.4 AI 与自动化（子 tab：问答 / 自动化）
- **问答**：QA 标题、模型 ID、上下文页数、历史保留天数、每 PDF 最大会话数、会话列表位置、知识范围；插入笔记 Q/A 块样式 + **实时预览保留**
- **自动化**：启用、目标笔记本、索引文档名、首次回填、模型 ID、摘要字数上限、调试日志

### 2.5 高级
- 调试与日志（调试开关、详细网络日志）
- **导入 / 导出 / 恢复默认**
- **旧版兼容设置（折叠，默认收起）**：ocrServerPath、ocrPort、ocrAutoStart、ocrEngine、unimernet*、ocrDevice 等旧键（内部迁移保留，UI 仅展示）

> 本批**不加入**：每引擎启动超时、打开数据目录/清理缓存入口（见 §7）。

## 3. 交互行为（已确认）

| 条目 | 决策 |
| --- | --- |
| 保存按钮 | **去掉**；底部固定「关闭」+「恢复默认」 |
| 即时生效 | 简单项改完立即写盘生效 |
| 需点“应用” | OCR 引擎目录/端口/启用、共享运行时/启动命令、PDF2zh 地址/服务目录、Doc2X CLI/鉴权 |
| 待应用提示 | 顶部黄色提示条 + 「立即应用」按钮 |
| 翻译服务地址/密钥 | 即时生效 + 「测试连接」 |
| OCR 弹窗内改格式/渲染器 | **仅本次生效，不回写默认值**；默认值只在设置里改 |
| 搜索 | 设置页顶部搜索框，**全局搜索 + 跳到对应页并高亮**；**不绑快捷键**（只用鼠标点） |
| 恢复默认 | 单项恢复 + 整页恢复（整页二次确认） |
| 逐项说明 | **只给复杂项加说明**（路径、模板、格式、翻译服务等） |
| 导出文件 | 用户选目录 + 自动命名 设置-YYYYMMDD-HHmm.json |
| 导入/导出 | 导出全部设置但**默认剔除密钥**；导入时选策略：覆盖 / 合并（默认，保留本机密钥）/ 仅导入选中模块 |
| 旧兼容键 | 高级页折叠区展示，默认收起 |
| OCR 历史入口 | **从设置页移到 Dock 面板** |
| 引擎卡片 | 检测 + 启动 / 停止 / 重启 |
| 翻译服务编辑 | 列表内嵌 + 详情弹窗 |
| 实施批次 | **分两批**（见 §6） |

## 5. 迁移与兼容

- 所有已有设置键读写逻辑保持不变，仅调整 UI 位置；不做破坏性重命名。
- 新增键（暂定）：`translationDefaultTargetLang`（翻译默认目标语言）、以及导入导出所需的文件版本字段（存于导出 JSON，不写入 settings）。
- 旧兼容键继续参与内部迁移，UI 放在高级页折叠区。
- 引擎目录/端口等“应用类”项修改后：先暂存，点“立即应用”后写盘并触发对应服务重连/重启。

## 9. 已确认的约定

1. **所有默认值维持现状**（不借重构改默认行为）。
2. 搜索**不绑快捷键**，仅鼠标点搜索框；不占用阅读器内 Ctrl+F。
3. 导出文件：用户选目录，自动命名 `设置-YYYYMMDD-HHmm.json`。
4. 逐项说明：只给复杂项（路径、模板、格式、翻译服务）加说明。
5. 本文档即需求定稿，作为第一批开工依据。
