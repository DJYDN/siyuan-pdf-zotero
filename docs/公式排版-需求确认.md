# OCR 公式源码排版 · 需求确认

> 状态：已实施（2026-11-16）
> 记录日期：2026-11-16
> 背景：OCR（UniMERNet / Pix2Text）输出的长公式是一整行、夹带大量 `\,` 间距命令，在思源公式块里可读性差、难定位编辑。

---

## 1. 目标

在不改变公式渲染结果的前提下，把**超长块级公式**的 LaTeX 源码格式化成多行 + 缩进，并压缩连续重复的间距命令，让思源公式块编辑器里的源码可读、可定位。

**硬约束**：数学模式里换行等价于空格，因此换行/缩进必须不改变渲染；不插入 `\\`、不改写环境结构、不改变公式语义。

---

## 2. 生效范围（已确认）

| 入口 | 是否排版 |
| --- | --- |
| OCR 插入笔记（块级公式 `$$...$$`） | ✅ |
| OCR 复制 / 自动复制（仅 LaTeX 类格式） | ✅ |
| PDF 阅读器 OCR 框选后插入 | ✅（走同一弹窗） |
| 已有公式块：右键「格式化公式」 | ✅ |
| 行内公式 `$...$` / `\(...\)` | ❌ 保持原样 |

---

## 3. 排版规则（已确认）

**触发判定（仅超长公式自动排版）**
- 字符数 > 120，或
- 含 `aligned` / `cases` / `matrix` / `pmatrix` / `bmatrix` / `gathered` / `split` / `array` 等多行环境；
- 两者任一成立即排版。

**换行位置**
1. `\begin{env}` 之后换行
2. `\\` 之后换行
3. `\end{env}` 之前换行
4. 顶层关系符（`=`、`\leq`、`\geq`、`\neq`、`\approx`、`\equiv`、`<`、`>`、`\to`、`\Rightarrow`、`\Leftrightarrow` 等）之后换行；处于 `\begin{...}` 环境内部时不拆（环境内靠原有 `\\` 分行，避免把 `aligned` 的一行再拆开）
5. 只在**深度 0**（不在嵌套花括号 / `\text{...}` 内部）处换行

**缩进**
- 每层嵌套 2 个空格（`\begin{env} ... \end{env}` 内层 +1）。

**间距命令**
- 连续重复的 `\,` / `\!` / `\;` / `\:` / `\quad` / `\qquad`（2 个及以上）压缩为 1 个；
- 单个间距命令保留，不删除。

**保证**
- 渲染结果与原文一致（只改空白字符与冗余间距）；
- 格式化幂等（对已格式化结果再跑一次不变化）；
- 排版器异常时静默回退原始 LaTeX，不阻断插入/复制。

---

## 4. 交互（已确认）

| 场景 | 行为 |
| --- | --- |
| OCR 弹窗 | 源码区右上角「自动排版」复选框，默认勾选；识别完成即显示排版后的源码（**不提供原始/格式化对比**） |
| 短公式 | 不排版，源码保持原样 |
| 复制 | 仅块级 LaTeX 包装格式（LaTeX 原样、`$$...$$`、`\[...\]`、align、equation）使用排版结果；行内包装（`$...$`、`\(...\)`）与 Typst / MathML 使用原始 LaTeX |
| 手动 | 右键公式块 → 自定义菜单「格式化公式」→ 直接替换块内容；可用 `Ctrl+Z` 撤销 |
| 手动触发不受阈值限制（短公式点格式化也会执行） | ✅ 已确认 |
| 失败处理 | 静默回退原始，不弹错误 |

---

## 5. 设置项

**不新增设置项**：规则固定（超长自动排版 + 弹窗临时开关）。

---

## 5.1 已确认的约定

1. 只处理块级公式；行内公式（`$...$`、`\(...\)`）在任何入口都不排版。
2. 复制格式中的行内包装（`$...$`、`\(...\)`）与 Typst / MathML 不做排版。
3. 右键「格式化公式」不受“超长”阈值限制。
4. 排版异常一律静默回退原始 LaTeX。
5. 本文件即需求定稿，作为实施依据。
