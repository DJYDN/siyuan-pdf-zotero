# SiYuan PDF × Zotero 安装、使用与配置说明

版本：**0.9.5**  
适用平台：SiYuan 3.8.7+ 桌面端（Windows）  
文档日期：2026-11-12

---

## 1. 这是什么

`siyuan-pdf-zotero` 是一个思源笔记桌面插件，主要能力：

- 在思源中直接阅读本地 PDF；
- 从 Zotero 文献库打开 PDF（Zotero 关闭时可使用缓存）；
- PDF 高亮、摘录、回跳、双向链接；
- 截图并插入笔记，截图可回溯到 PDF 页面/区域；
- 选区翻译，支持多个翻译服务；
- 整篇 PDF 翻译：
  - Doc2X（官方 CLI，个人账号会员）；
  - PDF2zh（本地便携 server，默认 Bing）；
- 翻译 PDF 历史列表与自定义保存目录；
- Zotero 引文、CSL 参考文献；
- 笔记本 AI 自动摘要与索引（可选）。

插件不会：

- 修改原始 PDF；
- 写入 Zotero SQLite；
- 修改思源 `.sy` 文件；
- 把 Zotero 会员、Doc2X 会员或 API Key 打包分发给其他人。

## 2. 包内内容

完整便携包：

```text
SiYuan-PDF2zh-Portable.zip
```

解压后：

```text
SiYuan-PDF2zh-Portable/
  plugin/
    siyuan-pdf-zotero-0.5.9.zip
    siyuan-pdf-zotero-0.5.9.sha256.txt
  pdf2zh-server/
    build/
    data/
    pz_server.py
    config.json
    启动 PDF2zh 服务.bat
  安装说明.txt
```

说明：

- `plugin/` 是思源插件；
- `pdf2zh-server/` 是已内置 Python 运行时的便携 PDF2zh server；
- PDF2zh 模型缓存已内置，首次翻译不需要下载模型；
- Doc2X 不包含在包内，需要单独安装官方 CLI 并登录自己的账号。

## 3. 安装插件

### 方式 A：思源内安装

1. 打开思源；
2. 进入：

```text
设置 → 集市 → 已下载
```

3. 选择“安装本地插件”；
4. 选择：

```text
SiYuan-PDF2zh-Portable/plugin/siyuan-pdf-zotero-0.5.9.zip
```

5. 安装完成后重载界面（F5）或重启思源。

不同 SiYuan 小版本的入口名称可能略有差异；如果找不到本地安装入口，使用方式 B。

### 方式 B：手动复制

将 `siyuan-pdf-zotero-0.5.9.zip` 解压为文件夹，放到：

```text
<思源工作空间>/data/plugins/siyuan-pdf-zotero/
```

确保该目录下直接有：

```text
plugin.json
index.js
```

然后重启思源。

安装后：

- 左侧栏出现 `PDF × Zotero` 图标；
- 打开后会看到 Dock 面板。

## 5. Zotero 配置（可选）

插件支持离线本地 PDF，不配置 Zotero 也能使用。

### 5.1 需要 Zotero 的功能

- Zotero 文献列表搜索；
- Zotero Collection；
- 从 Zotero 文献条目打开 PDF；
- 从 Zotero 元数据插入引文；
- 使用缓存中的 CSL 数据生成参考文献。

### 5.2 配置项

打开插件设置 → **Zotero 与阅读**：

```text
Zotero Local API 地址：http://127.0.0.1:23119
Zotero 数据目录：例如 E:\Tools\Zotero
库 ID：个人库填 0
```

点击 Dock 的 `刷新` 读取 Zotero。

Zotero 需满足：

- Zotero 7+；
- Zotero 设置 → 高级 → 允许其他应用与本机 Zotero 通信；
- PDF 是 Zotero 条目的附件；
- PDF 文件实际存在（`storage:` 或可访问的链接文件）。

### 5.3 离线打开

第一次在 Zotero 运行时点击刷新，会缓存：

- 文献元数据；
- Collection；
- PDF 附件路径。

之后关闭 Zotero，仍可通过缓存打开已有 PDF。

如果附件路径缓存不完整，插件会只读扫描：

```text
<Zotero 数据目录>/zotero.sqlite
```

补齐附件路径。该操作**只读**，不会写 Zotero 数据库。

如果 Zotero 数据库被占用，可能提示 `database is locked`；重新打开插件或稍后再试即可，不影响已有缓存。

### 5.4 显示模式

Zotero 与阅读：

- 悬浮预览触发方式：
  - 直接悬停；
  - 按住 Alt 再悬停。
- 摘录可见模板，支持 `{text}`、`{page}`、`{title}`。
- 默认引用样式：
  - GB/T 7714；
  - APA；
  - IEEE。

## 6. 本地 PDF 阅读

### 6.1 打开 PDF

Dock → `打开本地 PDF`。

打开后会在思源内以 PDF 标签页显示，支持：

- 页码跳转；
- 适合宽度 / 自定义缩放；
- 目录；
- 搜索；
- 标注面板；
- 反链面板；
- 上一页 / 下一页；
- 阅读位置保存。

### 6.2 高亮与摘录

选中 PDF 文本后右键：

- 仅高亮；
- 高亮并插入笔记；
- 复制链接；
- 复制引用。

支持 PDF++ 风格：

- Link；
- Embed；
- Callout；
- Quote in callout；
- 显示文字格式：标题与页码、页码、文本、Emoji、无。

设置位置：

```text
设置 → Zotero 与阅读
```

### 6.3 截图

PDF 顶部工具栏截图按钮 → 拖拽矩形区域。

截图可以：

- 插入笔记；
- 作为可回溯链接；
- 点击回到 PDF 对应页面/区域。

### 6.4 阅读会话

插件会保存当前打开过的 PDF 标签和阅读位置。  
重启后只恢复退出时仍打开的 PDF，不会无条件打开最后阅读的 PDF。

## 7. 选区翻译

### 7.1 打开

设置 → **选区翻译**：

```text
启用选区翻译
选中文本后自动翻译
译文中显示原文
目标语言
最短字符
当前翻译服务
```

默认：

```text
自动翻译：开启
```

### 7.2 使用

在 PDF 中选中文本：

- 自动翻译（默认开启）；
- 或右键选择 `Translate selection`。

浮窗显示：

- 原文；
- 译文；
- 服务名；
- 目标语言。

按钮：

- 复制译文；
- 写入标注；
- 关闭。

### 7.3 翻译服务

设置 → 选区翻译 → `配置翻译服务`。

内置 10 个服务类型：

1. 思源内置 AI；
2. OpenAI 兼容；
3. DeepL；
4. Google Translate；
5. 百度翻译；
6. 有道智云；
7. 腾讯云翻译；
8. 阿里云翻译；
9. Azure Translator；
10. 彩云小译。

每个服务可配置：

- 名称；
- 启用；
- Base URL；
- API Key / 凭证；
- 模型。

凭证格式：

```text
百度：appid#secret
有道：appKey#appSecret
腾讯：secretId#secretKey#region
阿里：accessKeyId#accessKeySecret
Azure：key#region
```

### 7.4 译文回溯

复制译文会生成：

```text
译文 ^[[译文]](siyuan://plugins/.../annotation?id=...)^
```

粘贴到思源笔记后：

- 译文正文保持普通文本；
- `[译文]` 是上标链接；
- 点击回到 PDF 原标注位置。

旧版已经粘贴的普通译文不会自动变成链接，需要重新复制。

## 7.5 PDF 问答

### 入口

PDF 顶部工具栏点击问答图标，打开右侧 Q&A 面板。

面板支持：

- 右侧停靠；
- 拖动面板左边缘调整宽度，宽度会保存；
- 点击 `◫` 切换为可拖动、可调整大小的浮动窗；
- 新对话；
- 关闭。

### 提问

输入问题，Enter 发送，Shift+Enter 换行。

AI 回答会流式逐字显示；如果服务端不支持流式，会按小段逐字展示完整回答。回答按 Markdown 渲染标题、列表、加粗、代码、表格和公式。

默认上下文：

- 有选中文本：选中文本 + 当前页 + 前后页；
- 无选中文本：当前页 + 前后页；
- 面板可切换“问全文”。

回答会：

- 尽量基于 PDF 内容；
- 标注 `[p.页码]` 来源；
- 上下文中没有依据时明确说明；
- 不混合其他 PDF 的对话。

### 插入笔记

每条 AI 回答提供：

```text
插入 Q/A
仅插入 A
```

插入为带边框的块：

```text
标题（可在设置中配置）
Q 问题
A 回答
来源：p.3
```

标题、Q/A 字体、颜色和字号插入后可在思源中原生编辑。

### 历史与多会话

- 一个 PDF 可以保存多个独立会话；
- 会话标题自动取第一条提问，可重命名；
- 顶部“会话”打开列表，可切换、新建、删除；
- 所有会话支持右键菜单：重命名、置顶/取消置顶、分享、多选、删除；
- 重命名是列表内联输入，不依赖浏览器 prompt；
- Q&A 回答文本可选中，右键可复制、复制为引用、插入笔记、全选；
- 会话按置顶、今天、昨天、7天内、更早分组；
- 会话列表位置可在设置中选择：问答面板内 / 左侧抽屉；
- 每个 PDF 最多 50 个会话；
- 关闭 PDF/退出思源后保留；
- 默认 15 天；只要会话在 15 天内更新过，就从最后更新时间重新计算 15 天；
- 不跨设备同步；
- 新对话会立即创建并切换到独立会话。

### 历史轮次跳转

当前会话消息区右侧有轮次轨：

- 每个用户提问一个节点；
- 滚动时自动高亮当前轮次；
- 点击节点跳转到该轮；
- 悬停显示问题摘要；
- 长对话中固定在侧边。


- 关闭 PDF/退出思源后保留；
- 默认保留 15 天；
- 可在设置中修改保留天数；
- 不跨设备同步；
- 新对话可清空当前 PDF 历史；
- 问答面板顶部“历史”按钮可列出 Q1、Q2……，点击跳转到对应轮次；
- 历史按 PDF 指纹兜底，重新导入或重定位 PDF 不会因 attachmentId 改变而丢对话。

### 附件

支持：

- TXT / Markdown；
- PDF；
- 内容会提取后作为问答上下文。

暂不支持图片视觉问答和 DOCX 文本提取。

### 设置

设置 → PDF 问答：

- Q/A 块标题、圆角、边框/背景颜色；
- 标题、Q、A 的颜色和字号；
- 字体；
- 设置区域内有实时预览，修改时立即显示效果；


```text
插件的 Q/A 块标题
AI 模型 ID（留空 = 思源当前模型）
默认上下文页数
历史保留天数
```

默认使用思源当前 AI，也可以指定模型 ID。

## 9. PDF2zh 本地翻译

### 9.1 配置

设置 → **PDF2zh**：

```text
PDF2zh 地址：http://127.0.0.1:8890
PDF2zh 服务目录：解压目录\pdf2zh-server
引擎：pdf2zh
服务名：bing
目标语言：zh-CN
输出：双语对照 / 纯译文
对照方向：左右 / 上下
```

便携包内置：

- Python 运行时；
- PDF2zh 1.9.11；
- Bing 翻译配置；
- BabelDOC / 模型缓存。

不需要安装 Python、uv、conda，也不需要 PDF2zh API Key。

### 9.2 启动

点击：

```text
检测 PDF2zh 环境
```

如果环境完整但服务未启动，插件会自动启动 PDF2zh。

也可以手动运行：

```text
pdf2zh-server\启动 PDF2zh 服务.bat
```

### 9.3 翻译

打开 PDF → 顶部“整篇 PDF 翻译”。

进度显示在右下角：

- 半透明圆环；
- 点击圆环展开进度和日志；
- 再次点击圆环或点击空白处收起；
- 成功后自动消失；
- 失败时保留红色圆环，点击查看错误。

### 9.4 已知限制

- PDF2zh 的 Bing 翻译依赖网络；
- 长文档可能需要数分钟；
- 目前设置了 15 分钟硬超时；
- 超时或服务错误会显示失败，不会无限等待；
- 如果 PDF2zh 长时间卡住，建议改用 Doc2X。

## 10. Doc2X 翻译

### 10.1 安装 Doc2X CLI

要求 Node.js 22+。

```bash
npm i -g @noedgeai-org/doc2x-cli@latest
```

检查：

```bash
doc2x --version
```

### 10.2 登录自己的 Doc2X 账号

```bash
doc2x login
```

浏览器完成 OAuth 授权。

登录后：

```bash
doc2x account status --json
doc2x models list --json
```

确认账号有会员/额度。

### 10.3 插件配置

设置 → **Doc2X**：

```text
Doc2X CLI 命令：doc2x
鉴权模式：oauth
目标语言：中文（zh）
翻译模型：从官方列表选择
术语表：从官方列表选择
输出：双语双栏 PDF / 纯译文重排 PDF
PDF 字体策略：全局一致 / 单页优先
翻译时忽略：表格 / 代码 / 图片 / 文献
上下文增强
保留原 PDF 字体颜色
```

打开 Doc2X 分类时，插件会自动执行一次检测，模型和术语表下拉来自：

```text
doc2x models list --json
doc2x term list --json
```

不硬编码模型名称。

### 10.4 使用

设置 → 整篇翻译：

```text
翻译提供方：Doc2X
```

保存后打开 PDF → 顶部整篇翻译。

### 10.5 限制

- 每个使用者必须使用自己的 Doc2X 账号；
- 不能共享会员或 OAuth Token；
- 必须联网；
- OAuth Token 失效后需要重新 `doc2x login`；
- CLI 固定排版输出为双语双栏 PDF；
- 标识符位置、双语 MD/HTML、排版 Word 等网页/客户端配置，公开 CLI 没有参数，插件不伪造；
- 不能把会员权益打包进插件分发。

## 14. 数据与备份

插件数据目录：

```text
<思源工作空间>/data/storage/petal/siyuan-pdf-zotero/
```

主要文件：

- `state-v1`：插件状态、设置、文献缓存、翻译历史；
- 备份文件由插件按策略写入；
- `translations/`：默认译文输出。

注意：

- 译文 PDF 不在原 PDF 所在目录；
- 译文 PDF 不进入思源 assets；
- 原 PDF 始终不被修改；
- 自定义译文目录后，旧译文仍保留在旧位置，历史记录仍可打开。

备份建议：

1. 备份 `state-v1`；
2. 备份自定义译文目录；
3. 备份插件 zip；
4. 不要备份或修改 Zotero SQLite。

## 15. 常见问题

### 15.1 Zotero 关闭后打不开文献

1. 确保之前点击过 `刷新` 建立缓存；
2. 检查 Zotero 数据目录是否正确；
3. 插件会尝试只读补齐 `zotero.sqlite` 中的附件；
4. 如果 PDF 文件已被移动/删除，缓存路径会失效，需要重新定位或重新下载。

### 15.2 PDF2zh 一直不结束

- 检查网络；
- 点击圆环查看日志；
- 当前已设置 15 分钟超时；
- 建议切换到 Doc2X；
- 确认 8890 没有被其他程序占用。

### 15.3 PDF2zh 500

- 点击圆环查看完整错误；
- 确认便携包中的 `pdf2zh-server` 是完整新版；
- 确认模型缓存目录存在；
- 重启 PDF2zh 服务；
- 检查服务名是否为小写 `bing`。

### 15.4 Doc2X 检测失败

```bash
doc2x --version
doc2x account status --json
doc2x models list --json
```

- 未登录：`doc2x login`；
- CLI 不在 PATH：填写完整路径；
- 模型/额度不足：检查 Doc2X 账户；
- OAuth 过期：重新登录。

### 15.5 选区翻译没有结果

- 设置 → 选区翻译 → 当前翻译服务；
- 检查 API Key；
- 思源内置 AI 需要在思源配置 AI；
- 网络或服务超时会显示错误。

### 15.6 译文上标没有链接

- 旧版复制的译文不会自动更新；
- 重新复制/写入一次；
- 新版复制的是思源原生上标链接 Markdown。

### 15.7 设置窗口切换分类跳动

0.5.3 起设置窗口固定尺寸，右侧内容独立滚动；如仍跳动，重载插件。

## 18. 最短使用路径

如果只想快速开始：

1. 解压便携包；
2. 安装插件；
3. Doc2X：
   - `npm i -g @noedgeai-org/doc2x-cli`
   - `doc2x login`
   - 设置 → 整篇翻译 → Doc2X → 检测环境 → 保存；
4. 打开 PDF；
5. 顶部“整篇 PDF 翻译”；
6. Dock → 译文 → 点击历史 PDF。
