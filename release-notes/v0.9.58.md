# SiYuan PDF × Zotero v0.9.58

> 本 Release 汇总 **v0.9.56 以来的全部改动**，统一为一个 Tag（`v0.9.58`）+ 一个 Release + 6 个附件。

在思源笔记里完成 **PDF 阅读、PDF++ 风格标注回跳、本地 OCR、免费划词翻译、本地整篇 PDF 翻译、Zotero 引文、文献矩阵、笔记模板、PDF 问答与 AI 自动化**。本地优先，不修改原始 PDF、不写 Zotero 数据库。

---

## 本次亮点

- **设置对话框重构**：5 个一级页 + 全局搜索 + 即时生效；重启类修改统一「立即应用」。
- **超长公式自动排版**：OCR 结果自动换行/缩进/压缩 `\,` 噪声，渲染不变；公式块右键「格式化公式」。
- **OCR 三引擎**：Texo / UniMERNet / Pix2Text 各自独立服务，公式优先级可配、失败自动降级。
- **Texo 风格识别弹窗**：源码/渲染同屏，KaTeX/MathLive 切换，10 种复制格式。
- **翻译目标语言统一**：一处默认 + 各引擎覆盖。
- 一批交互修复：ESC 关 MathLive 键盘、ESC 取消整篇翻译、ESC 退出框选/截图、弹窗尺寸不跳动、遮罩显隐修复等。

## 更新内容（v0.9.56 → v0.9.58）

### 设置

- 8 个零散一级页收敛为 5 个：连接与阅读 / 翻译 / OCR / AI 与自动化 / 高级；
- 翻译页子 tab：选区 / 整篇 / 服务；AI 页子 tab：PDF 问答 / 笔记本自动摘要；
- OCR 页折叠块：引擎与服务 / 识别路由 / 行为与格式；
- 顶部全局搜索：过滤设置项并跳页高亮；
- 去掉保存按钮：简单项即时生效；引擎目录、PDF2zh 地址、Doc2X CLI、共享运行时等需点顶部「立即应用」；关闭时若有未应用修改二次确认；
- 翻译服务内嵌列表（启用 / 当前使用 / 编辑 / 测试连接），地址与密钥即时生效；
- OCR 历史入口从设置移到 Dock；
- 旧兼容键集中到「高级 › 旧版兼容设置」折叠区。

### 公式排版

- 新增安全 LaTeX 排版器：超长公式（>120 字符或含 `aligned/cases/matrix/gathered/split/array`）自动换行 + 2 空格缩进，压缩连续间距命令；
- 不插入 `\\`、不改环境结构，渲染结果不变；`\text{}` 内原样保留；异常静默回退；
- OCR 弹窗「自动排版」开关默认开启；插入/复制用排版结果，行内包装与 Typst/MathML 用原始源码；
- 公式块右键「格式化公式 / 复制 LaTeX」，可 `Ctrl+Z` 撤销。

### OCR

- 三引擎独立服务：Texo（8893，20M ONNX，纯 CPU）、UniMERNet（8892，transformers）、Pix2Text（8891，公式/文本/混合）；
- 新增独立便携包：`OCR-Texo-Portable.zip`、`OCR-UniMERNet-Portable.zip`、`OCR-Pix2Text-Portable.zip`；
- 兼容旧 `OCR-Service-Portable`（同目录引擎共用服务）；
- 引擎卡片：启用/目录/端口/自动启动/状态/检测/启动/停止/重启；可选共享 Python 运行时；
- 公式优先级（默认 Texo → UniMERNet → Pix2Text）失败自动降级；文本/混合引擎单独指定；
- 弹窗：源码在上、渲染在下同屏；单行操作条；自动排版；粘贴/拖拽/换图重识别；示例图；复制 10 种格式；自动复制；文本结果独立处理；
- 修复：遮罩 hidden 失效、双窗格、下拉箭头遮挡、MathLive 加载无提示、换图重识别误走文本引擎、ESC 不关 MathLive 键盘。

### 翻译

- 目标语言统一为「默认 + 覆盖」（选区 / PDF2zh / Doc2X）；
- 整篇翻译支持 ESC 退出等待（PDF2zh / Doc2X），不再强制打开结果；
- 译文历史、输出目录、PDF2zh / Doc2X 参数保持可用；
- 划词翻译支持 12 种服务，免费服务无需 Key。

### 其它修复

- ESC 退出截图 / 矩形框选 / OCR 框选模式；
- 「粘贴 / 选择图片」优先读取剪贴板图片；
- 文本识别结果不触发自动复制、不误当公式；
- 公式块多行渲染与滚动优化。

### 补充修复（引擎目录与自动索引）

- OCR 引擎目录自动识别：选错包（例如把旧版 ocr-server 填给 Texo）会提示并**阻止保存**；
- 多个引擎指向同一目录时自动统一端口，并显示「共用端口」；
- 「检测」会自动拉起服务；启动失败时显示具体错误与服务日志尾部；
- PDF2zh 服务目录改为目录选择器（选整包或其中的 pdf2zh-server 目录均可）；
- 解压到插件目录的服务包会被自动索引并填入设置。

### Doc2X 增强

- 模型列表读取官方 `doc2x models list`：仅显示当前账号可用模型，并标注「需订阅」；
- 输出改为「纯译文 / 对照翻译」：只有对照翻译才显示「翻译类型」（固定排版双栏 PDF / 文档型 Markdown）；
- 新增解析模型配置：图片 OCR 模型（doc2x / mathpix）与官方视觉模型可选；
- PDF→Markdown 转换参数化：Dock「解析PDF为Md到笔记」使用解析模型，「翻译PDF为Md到笔记」使用翻译模型；
- PDF2zh 选择纯译文时自动隐藏「对照方向」。
- 未启用的引擎也会检查目录类型/脚本/运行时（勾选启用后才会自动启动）。
- 选择引擎目录时自动采用包内 config.json 的端口（Pix2Text 8891 / UniMERNet 8892 / Texo 8893）。

### Doc2X 解析库与解析翻译

- Dock「译文」改名为「解析翻译」，顶部下拉可筛选：全部 / 解析结果 / 翻译结果；
- 解析结果保存到插件数据目录，解析前如已有结果会询问「覆盖 / 保留为新版本 / 取消」；
- 解析库上限默认 50 条或 2GB，超出自动清理最旧记录（设置里可调）；
- 解析完成后弹预览：渲染/源码切换、清洗项可调，可插入光标、新建文档或仅保存；
- 点击解析记录会以真实思源文档打开（图片、公式、表格与笔记一致渲染），右键仍可预览/插入；
- 解析结果右键支持：以笔记文档打开、预览/插入、翻译、打开 Markdown、定位原 PDF、删除；
- Dock 筛选（全部/仅解析/仅翻译）现在会同时过滤解析 MD 和翻译 PDF。
- 翻译弹窗支持两种方式：Doc2X 保版翻译（提示重新解析并消耗页数）/ 快速翻译已有 Markdown（不消耗 Doc2X 额度，公式表格保持原文，可选仅译文或双语）；
- 样式清洗：`\[...\]`→`$$...$$`、`\(...\)`→`$...$`、HTML 表格转 Markdown、移除 Doc2X 包装标签，保留 raw.md 备份。

### Zotero 离线模式

- Zotero 未启动时，只读打开本机 zotero.sqlite，离线读取文献列表（标题/作者/年份/DOI/摘要）、分类、标签归属与 PDF 附件路径；
- 离线条目可直接打开对应 PDF；插件启动时若 Local API 不可用会自动切换到离线数据；
- Zotero 文献列表改为无限滚动（每批 40 条，滚到底自动加载），移除分页按钮；
- 设置 → Zotero 连接新增「Zotero 未运行时读取本机 zotero.sqlite」开关；
- 说明：受运行环境 SQLite 限制（node:sqlite 未启用 FTS5），离线全文索引搜索暂不可用，全文搜索仍需启动 Zotero。

## 安装

### 插件

1. 思源桌面版 **3.8.7+**；
2. 设置 → 集市 → 已下载 → 安装本地插件 → 选择 `siyuan-pdf-zotero-0.9.58.zip`；
3. 启用插件；右侧栏出现 **PDF × Zotero** Dock。

### 离线功能包（可选，解压即用，均自带运行时）

| 包 | 装法 |
|---|---|
| `OCR-Texo-Portable.zip` | 解压 → 设置 → OCR → Texo 卡片选择目录并启用 → 检测 |
| `OCR-UniMERNet-Portable.zip` | 解压 → 设置 → OCR → UniMERNet 卡片选择目录并启用 → 检测 |
| `OCR-Pix2Text-Portable.zip` | 解压 → 设置 → OCR → Pix2Text 卡片选择目录并启用 → 检测（首次启动 1–3 分钟） |
| `OCR-Service-Portable.zip` | 旧版共用服务，兼容保留 |
| `SiYuan-PDF2zh-Portable.zip` | 解压 → 设置 → 翻译 › 整篇 → 填 PDF2zh 服务目录 → 检测 |

> 三个 OCR 引擎可只装一个，也可多个共存；公式识别建议装 Texo（最快）或 UniMERNet；表格/整页文字用 Pix2Text。

## 升级说明

- 旧 `OCR-Service-Portable` 配置会自动迁移为 Pix2Text + UniMERNet 共用服务，无需重配；
- 所有设置默认值保持 v0.9.56 行为，不因重构改变默认；
- 新增 `translationDefaultTargetLang`（默认目标语言），迁移时用原选区目标语言初始化；
- 需要 `.sy` 设置迁移时会自动完成；如遇异常可在「高级 › 旧版兼容设置」中检查旧键。

---

## 已知限制

- 大型多行公式仍可能识别错误，需人工校对；自动排版只改空白，不修复识别错误；
- Texo 只识别公式；超长公式可能触发 token 上限提示；
- Pix2Text / UniMERNet 首次启动较慢（1–3 分钟），之后常驻；
- 旧共用包中的 UniMERNet 受原模型包限制，建议使用独立包；
- PDF2zh 依赖网络翻译服务（默认 Bing）；
- 模板会执行本地 JS，请只使用可信模板；
- 写回 PDF 标注会修改源文件，默认关闭。
