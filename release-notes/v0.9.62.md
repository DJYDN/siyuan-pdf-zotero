# SiYuan PDF × Zotero v0.9.62

## 本版更新

### Zotero Dock

- Zotero 文献标题行合并为单行，去掉独立状态条与匹配数字段；
- 在线 / 离线 / 未连接改为与「刷新」同款按钮样式，横排并列、等大小、不可点击；按钮本身着色：绿色=在线、黄色=离线、灰色=未连接。

### PDF 截图 / OCR 框选光标

- 进入截图、区域截图、OCR 框选后，全窗口强制十字光标，覆盖文字层的 I-beam / 按钮 pointer / 高亮菜单光标；
- 直到选区完成或按 ESC 退出才恢复。

- 旧的便携包可继续使用，不需要立即删除。
