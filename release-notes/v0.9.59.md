# SiYuan PDF × Zotero v0.9.59

> 本次发布汇总 v0.9.58 之后的全部改动：Zotero 离线模式、解析/翻译历史、Doc2X 解析库与翻译弹窗、OCR 引擎目录识别等。

## 本版更新

### Zotero 离线模式

- Zotero 未启动时只读打开本机 `zotero.sqlite`，离线读取文献列表（标题/作者/年份/DOI/摘要）、分类、标签归属与 PDF 附件路径；
- 离线条目可直接打开 PDF；插件启动/刷新时检测 Local API，不可用自动切换离线数据；
- 设置 → Zotero 连接新增「Zotero 未运行时读取本机 zotero.sqlite」开关；
- 说明：受运行环境 SQLite 限制（node:sqlite 无 FTS5），离线全文索引搜索暂不可用，全文搜索仍需启动 Zotero。

### 解析与翻译历史

- Dock「译文」改名为「解析翻译」，下拉筛选：全部 / 仅解析结果 / 仅翻译结果；Zotero 文献列表改为无限滚动（每批 40 条）；
- 解析结果保存到插件数据目录，同一 PDF 重复解析前询问「覆盖 / 保留为新版本 / 取消」；
- 解析库默认上限 50 条 / 2GB，超出自动清理最旧记录（设置可调）；
- 点击解析记录以真实思源文档打开（图片、公式、表格正常渲染），右键支持以文档打开、预览/插入、翻译、打开 Markdown、定位原 PDF、删除；
- 解析预览支持渲染/源码切换与清洗项开关，可插入光标、新建文档或仅保存；
- 解析结果翻译弹窗：Doc2X 保版翻译（提示重新解析并消耗页数）/ 快速翻译已有 Markdown（不消耗 Doc2X 额度，公式表格保持原文，可选仅译文或双语）；
- 样式清洗：`\[...\]`→`$$...$$`、`\(...\)`→`$...$`、HTML 表格转 Markdown、移除 Doc2X 包装标签，保留 raw.md 备份。

### Doc2X

- 模型下拉实时读取官方 `doc2x models list`，仅显示账号可用模型并标注「需订阅」；
- 输出改为「纯译文 / 对照翻译」，仅对照翻译显示翻译类型（固定排版双栏 PDF / 文档型 Markdown）；
- 新增解析模型配置（doc2x / mathpix 图片模型 + 官方视觉模型），PDF→Markdown 参数化；
- PDF2zh 选择纯译文时隐藏「对照方向」。

### OCR 引擎

- 未启用引擎也会检查目录类型/脚本/运行时；选择目录自动采用包内端口（Pix2Text 8891 / UniMERNet 8892 / Texo 8893）；
- 「检测」自动拉起服务，失败显示具体错误与服务日志；插件目录下的服务包自动索引填入；
- 旧版共用服务不能再用于 Texo，目录不匹配会阻止保存；
- PDF2zh 服务目录改为目录选择器；Dock 版本号修复（不再显示 v0.1.0）。

## 安装

1. 思源桌面版 3.8.7+；
2. `设置 → 集市 → 已下载 → 安装本地插件`，选择 `siyuan-pdf-zotero-0.9.59.zip`（zip 根目录即插件文件，无嵌套）；
3. 启用插件，右侧栏出现「PDF × Zotero」Dock。

## 升级

- 直接安装 0.9.59 包覆盖旧版即可，设置与数据会自动迁移；
- OCR 引擎包不需要重新下载；若原本指向旧版 `ocr-server`，请按新设置页提示改为对应引擎包目录。

## 已知限制

- 离线模式不支持全文索引搜索（全文搜索需启动 Zotero）；
- Doc2X CLI 不能复用解析结果、无页码范围，保版翻译会重新解析并消耗页数；
- 复杂合并表格仍保留原始 HTML，公式识别错误需人工校对。
