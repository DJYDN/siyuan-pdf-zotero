# SiYuan PDF × Zotero v0.9.96

> 本版汇总 **v0.9.64 以来的全部改动**（v0.9.65 → v0.9.96 共 32 个版本），首次加入两大新模块：**文献网络图谱** 与 **阅读统计/画廊**。

## 本版重点

### 文献网络图谱（Connected Papers 式）

- 在文献列表右键「文献网络（先期 / 衍生）」，或 Dock 顶部「文献网络」输入 DOI / 标题作为种子；
- 从 OpenAlex 拉取**参考文献（先期工作）**、**引用它的论文（衍生工作）**与相关文献，按共被引相似度做力导向布局；
- **悬停**节点高亮邻居与连线、其余变暗，并显示跟随鼠标的提示；点击在右栏看详情（含摘要）；双击打开原文；
- 「展开邻居」把该节点的参考文献与引文并入图；点击工具条切换先期/衍生高亮，侧栏同步显示 Top 10；
- 右栏「打开原文」优先打开本地 Zotero 或已导入的 PDF，本地没有才回落到 DOI 网页；
- **列表视图**：整窗表格，列为 Title / Authors / Year / Citations / References / Similarity to origin，点击表头排序，`⭳ Download` 导出 CSV；
- 窗口支持 8 方向拖拽调整大小、平滑滚轮缩放（围绕光标）、跟随窗口自适应重排；
- 设置 → 文献网络（OpenAlex）：可填免费 API Key，不填共用公共额度（容易限流）。

### 阅读统计与阅读记录

- 阅读器每 10 秒记录当前页停留时间（窗口失焦 / 标签页隐藏 / 闲置超阈值即停表）；
- 派生**阅读进度、累计时长、最近阅读**与「未读 / 在读 / 已读」状态；
- Dock 的「阅读中 / 最近 / Zotero」列表新增进度条与状态、时长文字；
- 按天留存阅读时长，矩阵新增「进度 / 时长 / 最近阅读」只读系统列；
- 数据只写入插件自身存储，**不修改 PDF，也不写 Zotero 数据库**。

### 矩阵画廊（第四种视图）

- 矩阵新增「画廊」视图：条目 / 笔记 / 标注三页签卡片墙；
- 条目卡片含 PDF 首页封面、标题、作者 / 年份 / 来源、可配置字段、简记、五星评级、阅读状态徽标；
- 可按条目类型 / 阅读进度 / 年份 / 期刊 / 评分**分列成瀑布流**，列头显示名称与数量；
- 支持范围切换（全部文库 / 当前矩阵项目）、布局（上下或左右）、字段与排序配置；
- 笔记卡片按来源归集，双击打开思源文档；标注卡片按颜色筛选，双击回到 PDF 原文位置。

### 其它增强

- **评级与简记**：列表行内五星单击打分，右键菜单评级或编辑简记；
- **期刊标签**：接入 easyScholar 开放接口（自备密钥，经思源 forwardProxy 请求），矩阵新增「期刊标签」列；
- **右键二级子菜单**：复制标题 / DOI / 作者 / BibTeX 收进「复制 ▸」子菜单，覆盖文献网络节点与详情菜单、画廊卡片菜单、Dock 文献与附件菜单；
- **OCR 性能**：启动预热、单实例锁、`/health` 不加载模型 + `/warmup`、插件单飞启动、备用引擎只回退已就绪实例；截图长边超过 2200px 自动降采样后再识别（可配置）。

### 修复

- 修复浮层内 `[hidden]` 被 `display:flex` 覆盖，筛选条、年份色阶、列表视图等隐藏元素错误显示；
- 修复文献网络窗口尺寸异常、横向溢出、右栏被挤出屏幕、关闭按钮失效；
- 点击节点不再把无关节点变淡（只有悬停才高亮）；
- 中间画布滚轮缩放改为平滑插值，不再卡顿。

## 安装 / 升级

### 插件本体（推荐走集市）

1. 思源桌面版 **3.8.7+**；
2. 设置 → 集市 → 搜索「PDF × Zotero」→ 安装并启用；
3. 右侧栏出现「PDF × Zotero」Dock。

> 也可下载 `package.zip` 后：设置 → 集市 → 已下载 → 安装本地插件。压缩包根目录直接是 `plugin.json` / `index.js`，无嵌套文件夹。

### 从旧版本升级

直接覆盖安装即可，**设置与阅读数据自动迁移**：
- `STATE_VERSION` 5、`MATRIX_SCHEMA_VERSION` 3，旧数据自动补默认值；
- 新增的「阅读状态」「期刊标签」等列会追加到已有矩阵项目。

### 离线功能包（按需，可选）

1. 解压对应的 `-Portable-0.9.63.zip` 到固定目录（均自带 Python 运行时，无需单独装 Python）；
2. 设置 → OCR → 对应引擎卡片「选择目录」→ 勾选启用 → 点「检测」；
3. PDF2zh：设置 → 翻译 › 整篇 → 填服务目录 → 检测。

> 建议先双击包内的 `CHECK-OCR.bat` 自检运行时、依赖与模型是否完整。

## 已知限制

- 文献网络依赖 OpenAlex 公共额度，未配置 API Key 时容易限流；
- 期刊标签需自备 easyScholar 密钥；
- 大型多行公式仍可能识别错误，需人工校对；自动排版只改空白，不修复识别错误；
- Pix2Text / UniMERNet 首次启动较慢（1–3 分钟），之后常驻；
- PDF2zh 依赖网络翻译服务（默认 Bing）；
- 写回 PDF 标注会修改源文件，默认关闭。
