# v0.9.56

## 新增

- 本地 OCR 引擎选择：Pix2Text / UniMERNet；
- UniMERNet 解压目录、配置文件、设备设置；
- Pix2Text 高级选项：设备、超时、MFD/MFR 模型、MFD 静态尺寸、MFR 上下文、拼写检查、表格识别；
- OCR PDF 框选、剪贴板 OCR、历史、收藏、替换选区；
- 文献矩阵：Collection 导入、研究字段、排序、分组、视图、批量编辑、行详情、AI 填充、CSV/SiYuan 表格导出；
- 默认笔记模板：Better Notes 兼容、模板导入、目标笔记本选择、安全刷新；
- PDF2zh / OCR 便携包独立发布。

## 修复 / 优化

- OCR 替换选区支持普通文本和公式块；
- 翻译弹窗支持点击空白/×关闭并清理选区；
- OCR 进度显示百分比，区分 PDF2zh 与 OCR；
- Bing 翻译失败时增加思源 AI 回退；
- 模板刷新只更新未编辑的块，保留用户编辑；
- 合并重复的截图与区域插入入口。

## 安装包

- `siyuan-pdf-zotero-0.9.56.zip`
- `SiYuan-PDF2zh-Portable.zip`
- `OCR-Service-Portable.zip`

## 说明

- UniMERNet 需要用户提供完整模型包，尚未完成真实模型验收；
- 大型多行公式仍建议人工校对；
- PDF2zh 需要网络访问翻译服务。
